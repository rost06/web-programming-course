# Учебный курс по веб-программированию

Новый курс по TypeScript, React и веб-программированию. Проект развивается поэтапно: после лекции студент получает задание, а на следующей практической встрече показывает результат и обсуждает вопросы.

## Занятия

| Лекция | Самостоятельная работа | Проверка |
| --- | --- | --- |
| [L0. Нулевое занятие](lessons/l0/README.md) | Стартовая практика HTML/CSS/JavaScript | P1 |
| [L1. TypeScript и данные](lessons/l1/README.md) | Модель и функции обработки данных | P2 |
| [L2. Компоненты React](lessons/l2/README.md) | Каталог и отображение заданий | P3 |
| [L3. Формы и состояние](lessons/l3/README.md) | Ответы и прохождение попытки | P4 |
| [L4. Черновик и восстановление](lessons/l4/README.md) | Сохранение между перезагрузками | P5 |
| [L5. HTTP и сервер](lessons/l5/README.md) | Подключение к учебному API | P6 |
| [L6. Проверка приложения](lessons/l6/README.md) | Тесты поведения | P7 |
| [L7. Разбор системы](lessons/l7/README.md) | Исправления и описание решения | Практика следующего полугодия |

Лекция проходит раз в две недели для обеих групп. Практика проверяет задание с предыдущей лекции: одна группа занимается в день лекции, вторая — через два дня. Точный срок сдачи сообщает преподаватель.

## Как работать

Рабочий процесс сохраняется:

```text
fork → clone → ветка задания → commit → push → pull request
```

Для L1 первая ветка приложения создаётся от синхронизированного `main`. Для L2 и следующих этапов новая ветка создаётся от предыдущей рабочей версии или SHA точки сдачи, чтобы код не терялся, даже если предыдущий PR ещё не завершён. Подробности: [гайд по Git и GitHub](docs/GITHUB_GUIDE.md).

Приложение развивается в одной папке [trainer](trainer/README.md). На L1 вы открываете существующую папку `trainer` и создаёте проект и файлы внутри неё; следующие этапы продолжают ту же рабочую версию. Материалы каждой лекции находятся в соответствующей папке `lessons/l1`–`lessons/l7`; код между папками переносить не нужно.
