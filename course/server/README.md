# Учебный API

Локальный сервер для учебного тренажёра. Он реализует контракт из [`course/CONTRACT.md`](../CONTRACT.md) на встроенном HTTP-модуле Node.js и слушает `http://localhost:3001`.

## Запуск

Из корня репозитория:

```sh
node course/server/server.mjs
```

Для запуска проверок:

```sh
node --test course/server/server.test.mjs
```

Команды одинаковы для Linux/macOS и Windows PowerShell. Данные загружаются из [`course/data/training-set.json`](../data/training-set.json).

## Ограничения

- Сервер учебный и не предназначен для production или официального тестирования.
- Аутентификации нет; любой локальный клиент может обращаться к API.
- Попытки хранятся ephemeral — только в памяти процесса и исчезают после перезапуска.
- Сервер не предоставляет ручное оценивание ответов `short-text`; такие ответы получают `pending-review`.
- Официальные ключи и закрытый банк заданий не входят в репозиторий.

## Учебная ошибка

Для проверки обработки ошибки добавьте к API-запросу заголовок `X-Demo-Fail: 1`. Сервер вернёт HTTP 500 и не изменит состояние данных. После этого уберите заголовок и повторите запрос.

Подробные маршруты, форматы JSON, правила валидации и статусы ответов описаны в [`course/CONTRACT.md`](../CONTRACT.md).
