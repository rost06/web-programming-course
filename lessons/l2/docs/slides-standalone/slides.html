React: props и состояние

Как превратить модель в маленький интерфейс на примере каталога книг.

Зачем React и Vite

React помогает разделить UI на компоненты и обновлять его по состоянию. Vite даёт dev-сервер и сборку. Эти инструменты подключаются к существующему проекту L1.

Термины

Компонент

Функция, возвращающая JSX.

Props

Вход компонента от родителя.

State

Изменяемые данные для нового рендера.

Key

Стабильный id элемента списка.

Подключение к проекту L1

Не используйте генератор поверх папки. Установите выбранные версии React, Vite и типов в существующий package.json; подробные команды и конфиги находятся в гайде.

Сохраните код и зависимости A1.

Mount и hello-проверка

index.html → <div id="root"></div> main.tsx → createRoot(root).render(<App />)

Минимальный hello-экран проверяет только инфраструктуру. После него напишите собственный UI.

Props — контракт функции

type BookRowProps = { isbn: string; title: string; onChoose: (isbn: string) => void; };

Данные идут вниз, callback сообщает о действии вверх.

Список книг и key

books.map((book) => ( <BookRow key={book.isbn} ... /> ))

ISBN описывает сущность. Индекс описывает только текущую позицию и хрупок после фильтра или сортировки.

Разные формы данных

Сначала проверяйте общее поле формы, затем читайте специальные свойства. Бумажная книга имеет страницы, аудиокнига — длительность.

Один и тот же принцип нужен для разных форм задания.

Одно состояние выбора

Храните минимальный идентификатор выбранной книги. По нему определяйте текущую карточку из исходного каталога; копию всего объекта в state не создавайте.

При отсутствии id покажите нейтральное состояние.

Безопасный текст

Данные книги выводятся как текст. Код или описание не должны превращаться во вставленный HTML и не должны исполняться браузером.

Самостоятельная работа A2

  • Сохранить доменный слой A1.
  • Собрать список и карточку через props.
  • Использовать стабильный task.id в key.
  • Хранить выбор в одном useState.
  • Сузить форму по kind и обработать отсутствие.

Граница и проверка

Без формы ответов, HTTP и сохранения. Выполните npm run check и npm run build, затем проверьте клавиатуру и узкое окно. Тестовый раннер подключается на L6.
