Термины и запуск

Тип описывает форму значения, массив хранит коллекцию, union выбирает одну из форм, а чистая функция возвращает результат без изменения входов. В проекте package.json хранит команды, package-lock.json фиксирует версии, node_modules/ содержит локальные пакеты, а tsconfig.json задаёт правила TypeScript.

npm run check
npm run demo

Полная последовательность создания проекта и проверка версии TypeScript описаны в гайде. Команды выполняются из trainer/ одинаково в Linux и Windows PowerShell. Интерактив показывает JavaScript-поведение на книгах.
