Исполняемые ожидания

Примеры выполняют JavaScript-проверки внутри страницы, без Vitest и без сети. Они показывают смысл ожиданий; настоящие тесты проекта запускаются после настройки командой npm test.

Перед запуском тестов

Vitest — раннер, RTL — библиотека пользовательских проверок, jsdom — тестовый DOM, mock — контролируемая замена API. При globals: false тесты импортируют API Vitest явно, а setup-файл вызывает afterEach(cleanup).

npm test
npm run build
