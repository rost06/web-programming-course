# L4. Черновик, восстановление и границы состояния

## Задание A4

В `trainer/` улучшите локальную попытку из A3. Выделите переходы в `useReducer`, а черновик синхронизируйте с `localStorage` через `useEffect`.

Требования:

- ответить, перейти между заданиями и перезагрузить страницу без потери черновика;
- хранить в черновике `version`, `setId`, `taskId`, `answers`, `status`;
- проверить JSON и совместимость с текущим набором до восстановления;
- показать понятное сообщение и предложить явный сброс для повреждённого или чужого черновика;
- не блокировать ввод, если `localStorage` недоступен;
- не восстанавливать `submitted` как редактируемую попытку.

Локальное состояние и серверное сохранение пока не смешиваются. API появится в A5.

## Модель

```ts
type Draft = {
  version: 1;
  setId: string;
  taskId: string;
  answers: Answer[];
  status: "in-progress" | "submitted";
};
```

Reducer меняет состояние только по явным событиям: `answerChanged`, `moved`, `restored`, `reset`, `submitted`. Эффект читает/пишет внешнее хранилище, но не становится вторым источником правды.

## Сдача и критерии

A4 сдаётся до следующей собственной практики. На P5 проверяется A4, а P4 проверяет ответы A3.

Проверьте: перезагрузку с ответом, повреждённый JSON, другой `setId`, явный сброс, отказ хранилища и завершённую попытку. Команды запуска описаны в [общем контракте курса](../../course/CONTRACT.md).
