Разбор поведения

Термины для разбора

  • Сценарий — входные данные и последовательность действий.
  • Факт — наблюдаемый результат.
  • Гипотеза — проверяемое объяснение факта.
  • Регрессия — нарушение ранее работающего поведения.

Связи

Путь одного ответа

Ввод → состояние → запрос
     → подтверждение → результат

На каждом переходе сохраняется идентификатор задания.

Покажите соответствующие места в своём проекте.

Состояние

Где находятся данные

  • Черновик: пользователь уже изменил ответ.
  • Подтверждение: сервер сохранил ответ.
  • Прогресс: вычисляется из заполненных ответов.

Эти значения могут измениться в разные моменты.

HTTP

Что подтверждает запрос

  • Запись в Network — запрос начат.
  • Response — ответ получен, статус нужно проверить.
  • Подтверждение сохранения — данные приняты по контракту.
HTTP 500 ≠ успешное сохранение

Результат

Ожидание проверки

{ status: "pending-review", score: null }

Текстовый ответ может быть принят, но ещё не оценён.

Интерфейс отображает статус сервера.
