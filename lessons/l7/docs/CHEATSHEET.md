# Краткая справка: проверка и разбор

[Задание](../README.md) · [Гайд](GUIDE.md) · [Интерактив](interactive.html)

| Наблюдение | Что оно подтверждает |
| --- | --- |
| Текст появился в поле | Ввод отображён локально |
| Запрос появился в Network | Браузер начал запрос |
| Получен Response | Есть HTTP-ответ; статус ещё нужно проверить |
| Сервер подтвердил запись | Действие принято согласно контракту |
| Повторное чтение вернуло запись | Запись доступна через API в проверенный момент |
| Один тест прошёл | Выполнено его конкретное ожидание |

Разбор: **сценарий → факт → гипотеза → проверка → причина → исправление → повторная проверка**.

Из `trainer/`, Linux и Windows PowerShell:

```sh
npm run check
npm run build
npm test
git rev-parse HEAD
```

Проект, зависимости и команды описаны в [инструкции запуска](../../../trainer/README.md). Сохраняйте SHA и результаты проверок вместе с PR.

Проверяйте значение score на null явно. Статус `pending-review` означает ожидание проверки, а не неправильный ответ. Типы, имена полей и допустимые переходы сверяйте с [контрактом](../../../course/CONTRACT.md).
