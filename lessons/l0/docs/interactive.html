Интерактивные примеры нулевого занятия

Откройте вкладки и измените пример. Важно не запомнить код, а увидеть, как HTML задаёт структуру, CSS отвечает за внешний вид, а JavaScript меняет поведение страницы.

Инструменты перед практикой

Node.js запускает инструменты JavaScript, npm управляет пакетами, редактор помогает работать с файлами, а Git сохраняет историю. На этой странице работают только HTML, CSS и JavaScript; trainer/ станет проектом на L1.

node --version
npm --version
git --version
code --version

Команды одинаковы в Linux и Windows PowerShell. Если команда редактора недоступна, откройте редактор через меню системы.

Расширенные материалы

Подробные материалы сгруппированы по темам и открываются по мере необходимости.

  • HTML: подробный конспект и расширенная шпаргалка
  • CSS: подробный конспект и практическая шпаргалка
  • JavaScript: подробный конспект и практическая шпаргалка
  • Отдельные интерактивы: HTML, CSS, JavaScript

Идея для стартовой практики: сначала сверстайте статичную страницу, затем добавьте только одно небольшое интерактивное действие и проверьте его через DevTools.
