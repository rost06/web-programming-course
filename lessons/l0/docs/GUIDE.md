# Гайд к нулевому занятию

Это короткий маршрут по стартовому заданию. Сначала попробуйте собрать свой вариант по требованиям, а затем используйте этот файл как рабочую справку: он помогает распределить работу между HTML, CSS и JavaScript и проверить результат.

Подробные объяснения и крупные примеры находятся в [расширенном справочнике](#расширенный-справочник). [Интерактивные примеры](interactive.html) показывают несколько небольших изменений в браузере.

## Перед началом: инструменты и роли

HTML описывает смысл и структуру страницы, CSS — её внешний вид, JavaScript — реакции на действия пользователя. Node.js нужен для запуска инструментов курса, npm — для установки и запуска пакетов, редактор — для работы с файлами, а Git — для истории изменений. На L0 вы применяете первые три веб-технологии, а Node.js и npm проверяете заранее для перехода к L1.

Установите Node.js 24 или новее, редактор и Git по инструкциям [README занятия](../README.md). В Linux и Windows PowerShell команды проверки одинаковы:

~~~sh
node --version
npm --version
git --version
code --version
~~~

Если команда `code` не добавлена в PATH, откройте редактор через меню системы и проверьте, что он открывает папку курса. На L0 команды npm для `trainer/` не запускаются: этот каталог станет проектом только на L1.

## 1. Спланируйте структуру страницы

Сначала определите разделы страницы и запишите их назначение:

- шапка и навигация;
- первый экран с именем фотографа;
- информация о фотографе;
- галерея;
- контакты;
- подвал.

Для крупных смысловых частей используйте семантические элементы HTML. Начать можно с неполной схемы:

~~~html
<header>...</header>

<main>
  <!-- разделы страницы -->
</main>

<footer>...</footer>
~~~

Внутри `main` разместите обязательные разделы задания, а затем свяжите их с навигацией через `id` и `href`. Расширенные варианты семантических блоков доступны в [HTML-шпаргалке](cheatsheet/1_html_tags_cheatsheet.md).

Тег section обычно получает заголовок и идентификатор, если на него ведёт навигация. Идентификатор в ссылке и значение href после символа # должны совпадать.

## 2. Подключайте изображения относительными путями

Изображения нулевого занятия находятся в папке images. Например:

~~~html
<img
  src="images/portrait_1.jpg"
  alt="Портретная фотография"
  width="800"
  height="600"
>
~~~

Атрибут alt описывает изображение. Если картинка только декоративная, используйте пустое значение alt, а не удаляйте атрибут.

Путь считается от файла, в котором он написан. Из index.html путь начинается с images/. Из файла внутри другой вложенной папки путь будет отличаться.

## 3. Сначала сделайте простой CSS

Начните с читаемого текста и базовых отступов:

~~~css
:root {
  color: #202124;
  background: #f7f4ef;
  font-family: Arial, sans-serif;
}

body {
  max-width: 1120px;
  margin: 0 auto;
  padding: 24px;
}

img {
  display: block;
  max-width: 100%;
  height: auto;
}
~~~

После этого оформите галерею. Grid удобен для равномерной сетки:

~~~css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

@media (max-width: 700px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}
~~~

Flexbox удобен для навигации и небольших групп элементов:

~~~css
nav {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
~~~

Не начинайте с большого количества эффектов. Сначала проверьте размеры, контраст, отступы и поведение на узком экране.

## 4. Добавляйте JavaScript только после основы

Для этого задания достаточно одной небольшой интерактивной функции. Например, показать сообщение после нажатия кнопки:

~~~html
<button type="button" id="contact-button">Показать контакты</button>
<p id="contact-message" hidden>Напишите: anna@example.com</p>
~~~

~~~js
const button = document.querySelector("#contact-button");
const message = document.querySelector("#contact-message");

button.addEventListener("click", () => {
  message.hidden = !message.hidden;
});
~~~

Если элемент может отсутствовать на странице, учитывайте это в коде:

~~~js
const button = document.querySelector("#contact-button");

if (button) {
  button.addEventListener("click", () => {
    console.log("Кнопка нажата");
  });
}
~~~

## 5. Проверяйте результат в браузере

Проверьте:

1. открываются ли все изображения;
2. работают ли ссылки навигации;
3. нет ли ошибок во вкладке Console;
4. не появляется ли горизонтальная прокрутка;
5. читается ли текст на узком экране;
6. можно ли пользоваться ссылками и кнопками с клавиатуры.

Если изменения не видны, обновите страницу без кэша или убедитесь, что редактируете подключённый файл.

## 6. Частые ошибки

### Изображение не загружается

Проверьте имя файла, расширение и регистр букв. На разных системах регистр может обрабатываться по-разному.

### Навигация не прокручивает страницу

Проверьте, что у ссылки есть href="#gallery", а у целевого элемента есть id="gallery".

### Стили не применяются

Проверьте путь в link rel="stylesheet" и вкладку Network в DevTools.

### JavaScript не запускается

Проверьте путь к script src, синтаксис и ошибки во вкладке Console.

### Сетка ломается на телефоне

Проверьте наличие viewport в head и добавьте media query для узкого экрана.

## 7. Локальное открытие

Для нулевого занятия сервер не требуется. Откройте `lessons/l0/index.html` двойным щелчком или перетащите файл в браузер. Все используемые CSS, JavaScript и изображения находятся в папке занятия.

## 8. Перед завершением

- обязательные разделы присутствуют;
- все шесть изображений загружаются;
- HTML читается без необходимости угадывать назначение блоков;
- CSS не содержит повторяющихся случайных правил;
- JavaScript не выдаёт ошибок;
- вы можете коротко объяснить, что сделали и что не успели.
