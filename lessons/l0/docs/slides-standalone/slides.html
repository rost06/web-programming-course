Git

Базовые термины

Три слоя веб-страницы

HTML

Язык разметки. Описывает смысл и структуру: заголовок, раздел, список, изображение, ссылку.

CSS

Таблицы стилей. Отвечают за цвета, размеры, отступы, расположение и адаптацию.

JavaScript

Язык программирования. Добавляет действия: открытие, фильтрацию, проверку формы и другие реакции.

HTML

Сначала смысл, потом оформление

<main>
  <section id="gallery">
    <h2>Избранные работы</h2>
    <figure>
      <img src="../../images/portrait_1.jpg"
           alt="Портретная фотография">
      <figcaption>Портретная съёмка</figcaption>
    </figure>
  </section>
</main>

Семантические элементы помогают человеку, браузеру и вспомогательным технологиям понять назначение содержимого.

CSS

Сетка должна работать на разных экранах

.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

@media (max-width: 700px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}

Адаптивность — это не отдельная «мобильная версия», а способность одной страницы сохранять читаемость при разной ширине.

JavaScript

Поведение начинается с события

const button = document.querySelector("#contact-button");
const message = document.querySelector("#contact-message");

button.addEventListener("click", () => {
  message.hidden = !message.hidden;
});

Событие — это то, что произошло на странице: клик, ввод текста, отправка формы или загрузка документа.

Отладка

Ошибка — это информация для проверки

Прочитать текст ошибки и найти файл.
Проверить путь к CSS, JavaScript или изображению.
Посмотреть элемент во вкладке Elements.
Проверить Console и Network.
Изменить одну вещь и проверить гипотезу.
Если не получилось — описать, что уже проверено.

Хороший вопрос содержит контекст: что ожидалось, что произошло и какие шаги уже выполнены.
