# Папка проекта trainer

`trainer/` — единая рабочая папка приложения курса. В ней пока нет `package.json`, lockfile, конфигурации сборщика и исходников: проект создаётся студентом на L1. Поэтому до выполнения L1 команды `npm` из этой папки запускать не нужно.

Это часть маршрута обучения:

1. На L0 вы сохраняете результат стартовой практики HTML/CSS/JavaScript — портфолио фотографа — в `lessons/l0/`.
2. На L1 самостоятельно создаёте в `trainer/` новый TypeScript-проект, устанавливаете зафиксированные версии инструментов, добавляете типы и функции A1.
3. На L2 к той же папке подключаете React и Vite, не перезаписывая проект генератором, и продолжаете с A1.
4. На L3–L5 расширяете эту же рабочую версию формами, черновиком и HTTP.
5. На L6 самостоятельно подключаете Vitest и React Testing Library, настраиваете тестовый скрипт и тестируете поведение.

Точные команды, минимальные конфигурационные фрагменты и порядок проверки находятся в материалах [L1](../lessons/l1/README.md), [L2](../lessons/l2/README.md) и [L6](../lessons/l6/README.md). Они создают только инфраструктуру и не заменяют вашу реализацию заданий.

## Учебный сервер

Сервер запускается из корня репозитория, а не из `trainer/`. Команда одинакова в Linux и Windows PowerShell:

```sh
node course/server/server.mjs
```

Он доступен на `http://localhost:3001`; формат маршрутов описан в [контракте](../course/CONTRACT.md). Сервер и [учебный JSON](../course/data/training-set.json) уже входят в репозиторий и не требуют переноса в `trainer/`.

## Порядок работы

После каждого этапа оставляйте проект в `trainer/`, фиксируйте рабочую точку коммитом и создавайте следующую ветку от версии, которая уже содержит предыдущий этап. Сверяйте команды с README текущего этапа: до L6 `npm test` не требуется и не используется, а на L6 тестовый скрипт и зависимости настраиваются вами.

[Занятия и порядок сдачи](../course/README.md).
